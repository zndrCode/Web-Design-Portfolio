## ✨ Features

- **🍱 Bento Grid Architecture:** Proportional 12-column modular grid layout inspired by modern design standards.
- **🌓 Seamless Dark Mode:** Instant theme detection matching system preference, persistent storage (`localStorage`), and zero flash of unstyled content (FOUC).
- **📱 Fully Responsive:** Clean reflow across mobile phones, tablets, and wide desktop screens.
- **⚡ Zero Bloat:** Built with pure semantic HTML5, modern CSS3 (Custom Properties & Grid), and lightweight vanilla JavaScript.
- **🎯 Active Scrollspy:** Navigation links highlight dynamically as sections come into view.
- **✉️ Interactive Contact Card:** Inline form validation with feedback states and direct email launch.
